# 视界 6371 · Take Her Eyes

一部在浏览器里运行的 3D 沉浸式感官互动体验，灵感致敬刘慈欣《带上她的眼睛》。  
以主角「陈舟」的身份戴上传感眼镜，替耳机另一端来自「落日六号」的「林微」走完地表的一天；并在走出草原后，通过「地球表面电台」与「寄出我的视野」工坊，让现实里的陌生人继续替彼此交换眼前的风景、声音与微风。

## 三大篇章联动

1. **序章 · 地球的一天** — 从清晨 `06:40` 到午夜 `00:00` 的八幕叙事体验，穿插 4 条伏笔线索、3 枚场景彩蛋与草原记忆胶片冲印导出；支持封面断点续游与直接跳幕回顾。
2. **地球表面电台** — 可拖拽交互的 3D 全息地球，内置 12 座中国城市地标手绘风景、封面「今日回声」直达、接力轻语、长按同频心跳与留言回声墙。
3. **寄出我的视野** — 感官明信片工坊：支持选取预设、上传本地照片、`Ctrl+V` 粘贴或移动端「拍下此刻」直拍，实时叠加暗房色调滤镜、空气粒子、环境声景、10 秒现场录音与 3D 目光注解，可在「冲印工坊」切换 4 套版式（暮靛星海 / 银盐拍立得 / 35mm 胶片 / 落日六号信笺）与地心邮戳生成高清 PNG（电台内也可冲印），并发布为公开/私密 `?signal=CODE` 分享链接（同设备支持两步撤回）。

## 八幕情绪弧线（序章）

1. **I · 晨雾对焦（`06:40`）** — 拖动 3D 双重光学对焦环拨开晨雾，同步野花光影与花香。
2. **II · 湖水听风（`09:30`）** — 轻划湖面激起两道水波后校准风声共振频段；锁定瞬间触发地表金属低鸣告警。
3. **III · 孤树蒲公英（`13:15`）** — 来到悬崖孤树下长按聚风，吹散漫山蒲公英。
4. **IV · 石拱回声（`15:50`）** — 在古老石拱前发出 3 次心光共振，唤回山谷回声。
5. **V · 黄昏晚雨（`18:10`）** — 暮雨降落，点接空中飘落的 5 滴晚雨并等待云开。
6. **VI · 轻舟聚萤（`19:45`）** — 轻点暮色湖岸，为停泊木船引来 6 簇呼吸流萤。
7. **VII · 专属星河（`22:30`）** — 在夜空按顺序连起 3 颗亮星，听见耳机深处最后的坦白。
8. **VIII · 落日六号（`00:00`）** — 信号随深度急剧衰减，穿越地壳与地幔下坠至 `6,371.4 KM` 地心，与暮靛金光中的她道别与立约，将线索与记忆胶片带入电台与工坊。

## 操作、无障碍与旅途印记

- **视角与漫步**：桌面端支持拖拽环顾、`WASD`/方向键漫步（`Shift` 加速）与 `Space` 发出心光；触屏端自动启用双虚拟摇杆。
- **电台视窗快捷**：支持陀螺仪视差；左右方向键或顶部箭头在非输入状态下快速切换上下份视野。
- **设置与舒适度（`SettingsDrawer`）**：四通道独立音量滑杆（总音量/环境声/语音与琴音/交互音效）、画质档位、减弱动效与封面快捷「闪烁抑制」开关。
- **旅程印记**：本机记录八幕进度、三枚彩蛋（漂流瓶 / 风化石碑 / 暮色流星）、同频心跳、回声与点亮城市等 9 枚本地里程碑。

## 技术栈

- **前端核心**：Vite 8（Rolldown 分包）+ React 19 + TypeScript + Tailwind CSS v4
- **3D 与着色器**：Three.js（程序化地形/草浪/阳光散射氛围后处理/湖水涟漪/降雪雨萤/穿越地心/全息地球）
- **音频引擎**：纯 Web Audio API 程序化声景合成与母带平衡 + 离线预生成角色语音引擎（46 条基于 `mimo-v2.5-tts` 预合成的静态 MP3 与耳机带通滤波，无需运行时配置密钥）
- **云端闭环**：`functions/routes.mjs` 无服务器接口 + PostgreSQL（`database/visions.sql`），含本机降级与 48 位设备凭证撤回校验

## 开发与构建

```bash
npm install
npm run dev      # 启动本地开发服务
npm run lint     # 运行 oxlint 代码体检
npm run build    # TypeScript 类型检查 + Vite 生产打包
```
