# 风信 · Windpost

一部在浏览器里运行的 3D 沉浸式感官互动艺术馆体验，灵感致敬刘慈欣《带上她的眼睛》。
以主角「陈舟」的身份踏入黎明实景 3D 草原、接通随身通信终端的加密来电并戴上脑机传感眼镜，替耳机另一端来自「落日六号」的「林微」走完地表的一天；并在走出草原后，通过 **「行星电台 · 3D 奇境」「穿云空降沉浸世界」「传感透镜」** 与 **「视野信箱 · 漂流邮局」**，延续对人间晴朗与灯火的接力记录。

> **在线体验（Qoder Sites）**：`https://windpost-lzi8utsygdd.qoder.zone/`  
> **当前版本**：`v5.0.0` · **奇境跃迁 · Project EARTH-CORE**（2026 Qoder 高校创造力大赛 · LifeHack 赛道）

## 评委 2 分钟速览指南

1. **实景 3D 活草原片头与纯净剧场模式（约 20s）**：桌面端打开首页即见实时 HDR 3D 黎明草原空中巡航（`LIVE 3D` 体云、草浪与湖光），随时可按键盘 **`H`** 一键隐去全部界面进入无框美术馆级纯净画面；点击「戴上她的眼睛」`900ms` 俯冲直入清晨草坡，接通 **SUNSET-06 加密来电**、触发 **赛博神经扫描 HUD** 与 **28 条 Qwen-TTS 多角色配音**。
2. **拨开地球 1/4 X 光地核剖面 · 穿壳直抵落日六号（约 30s）**：进入「行星电台」旋转配备 **Fresnel 轨道大气散射 + 昼夜晨昏线 + 全球都会夜景** 的 3D 地球；点击 **「🪩 地球 X 光剖面」** 实时切开地壳与云层，展现三向地质层纹剖面楔、流动岩浆下地幔、液态铁镍外核、炽白固态内核与悬浮其间的 **「落日六号 SUNSET-06」**，轻触地核或点击 **「⬇ 穿壳直抵落日六号 · 6,371.4 KM」** 触发 `1.25s` 熔岩穿壳下潜动画无缝降临地心耐压舱。
3. **从行星电台穿云空降任意 3D 城市实景（约 30s）**：直接点击电台右侧的 11 座全 3D 地表城市卡片（上海、南京、武汉、大理、哈尔滨、拉萨、悉尼、夏威夷、雷克雅未克、京都、巴黎），伴随 `420 KM → 0.0 KM` 晨曦穿云俯冲直接降落该城第一人称漫步街道；第 12 境「落日六号」从地球 X 光剖面进入。真实照片投稿仍进入曲面实景视窗，也可释放 **「◉ 发送地心共鸣波」** 唤醒全球城市信标。
4. **全局「传感透镜」、乘风滑翔与 15 键草原风铃琴（约 40s）**：随时点击顶栏 **「传感透镜」** 采集眼前真实光影与气息并直送「视野信箱」贴邮票寄出；在序章草原按 `F` / 双击 `Space` 开启 **「🪽 乘风滑翔」**、吹散蒲公英、放飞 **「☄ 许愿流星」** 或弹奏 15 键 **「🔔 草原风铃琴」**（3D 天空升起音符光柱）。

## 三大主模块与 Project EARTH-CORE 核心架构

1. **序章 · 地球的一天（桌面 3D 活片头 + 感官沙盒）** — 半径 `220m` 的连续起伏草原、桌面端实时 3D 封面巡航与 `900ms` 零摩擦直入、随身加密来电与导演剪辑版八幕情感剧本：配备 4 条山谷小径、18 块湖心踏石长堤、5 处开放地标、顶部罗盘与 3 处 `[E]` 观景长椅；探索模式内置 **乘风滑翔 (`F` / 双击 `Space`)**、蒲公英/晚雨/流萤/许愿流星天气玩具、**15 键双音色草原风铃琴**、`24h` 自由天色调节、`[P]` 草原随手拍、`[J]` 观测手账与 **`[H]` 纯净剧场模式**。
2. **行星电台 · 3D 奇境（地球总览 + 全屏沉浸世界 + 我的纪念册）** — 可拖拽旋转与区域筛选（全球 11 城 / 南半球盛夏 / 异域极境 / 中国城市）的 3D 全息地球：自定义 GLSL **Fresnel 大气散射光晕壳**、**昼夜晨昏线与全球都会夜景灯网**、**「◉ 发送地心共鸣波」**、以及 5.0 打造的 **「🪩 地球 X 光剖面」**（1/4 实体地质层纹剖面楔 + 流动岩浆地幔 + 液态外核 + 固态内核 + 可点击「落日六号」圣殿）。11 座地表预设全部直接经 `CloudDiveOverlay` 穿云进入对应全屏 3D 奇境，老 2D 矢量城市不再进入默认电台但旧书签仍兼容；真实照片投稿继续进入 `SignalViewer`。沉浸态保留漫步/飞行/晨暮夜/奇境奇遇/乐台/吹气/返回地球，右上角接入真实 PostgreSQL 回声抽屉与 16:9 拍照寄信，电台总览可直接打开我的纪念册与 12 枚印记墙。
3. **视野信箱 · 漂流邮局 & 传感透镜** — 顶栏随时唤起 **「传感透镜」** 采集眼前风景并无缝流转至纪念册或视野信箱；支持直接导入已拍风景卡片、配 8 枚当地邮票、信笺边框与天气贴纸，附随实时环境音与麦克风录音生成 `?signal=CODE` 分享与 4 套 `1800×2300` 高清 PNG 明信片冲印；内置「漂流收件箱」，可随时拆阅远方来信并收进纪念册。
> **画廊级视觉原则**：以建筑剪影、水面倒影与晨昏天光为主角，Bloom 仅在真正高光处形成柔滑光晕；常驻光尘、雨雪、花瓣、火星、风痕与跨洲弧线均按低密度、小尺寸、低透明度校准，保留全部互动但让画面保持清透呼吸感。

4. **工程性能、AI 语音与全栈容灾**：
   - **极速首屏与按需分包**：移动端与弱性能设备保持轻量 2D 黎明封面按需懒加载 Three.js，桌面端空闲 `650ms` 无缝拉起 HDR 实时 3D 巡航片头，兼顾首秒打开速度与震撼第一眼。
   - **序章 28 条 Qwen-TTS 原声 + 终局留白**：基于 `qwen3-tts-flash` + 情绪指令批量合成（`Serena` 林微、`Kai` 旁白），覆盖序章全部 28 条语音；行星电台保留各城环境声景、电台配乐与旅人现场录音，最终章穿越地心特意保留沉默主角与纯音乐环境声，让林微的告别成为耳边最后的真人声音。
   - **Serverless PostgreSQL + IndexedDB 双模运行与 `#/admin` 后台**：后端由 Qoder Sites Functions + PostgreSQL 提供公网视野 Feed、心跳、回声及 `owner_token` 自主撤回；网络离线时无缝降级本地存储；配备凭 `ADMIN_TOKEN` 鉴权的轻量 `#/admin` 站长审核后台（公开/私密切换、删帖、清留言）。

## 八幕情绪弧线（序章）

1. **I · 晨雾触花（`06:40`）** — 拨开晨雾，轻触随风摇曳发光的草坡野花。
2. **II · 湖畔听风（`09:30`）** — 轻划湖面激起水波并校准风频；锁频瞬间触发地表金属异响警报。
3. **III · 孤树蒲公英（`13:15`）** — 在悬崖孤树下聚起午后暖风，看白绒替她向高处飞去。
4. **IV · 石拱回声（`15:50`）** — 在山腰石拱前轻叩三次呼唤，唤回山谷回声并寄存约定。
5. **V · 手心晚雨（`18:10`）** — 应她轻声恳求「替我摸一摸雨水」，接住 5 滴晚雨并等待云开。
6. **VI · 轻舟聚萤（`19:45`）** — 轻点暮色湖岸，为停泊木船引来 6 簇呼吸流萤。
7. **VII · 真相揭开（`22:30`）** — 连起夜空 3 颗亮星，听她卸下观测站谎言，触发地核信标过载与脑机透视。
8. **VIII · 落日六号（`00:00`）** — 垂直穿越地壳与地幔下坠至 `6,371.4 KM`，在静默心跳共振与钛金球形耐压舱的琥珀微光里，替她带上人间的晴朗。

## 开发、配音合成与构建

```bash
npm install
npm run dev      # 启动本地开发服务
npm run lint     # 运行 oxlint 代码体检
npm run test     # 运行 Vitest 单元测试
npm run build    # TypeScript 类型检查 + Vite 生产打包

# （可选）使用阿里云百炼 Qwen-TTS 批量重新合成语音 MP3
$env:DASHSCOPE_API_KEY="sk-你的百炼Key"
node scripts/generate-voices.mjs
```
