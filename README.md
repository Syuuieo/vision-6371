# 视界 6371 · Take Her Eyes

一部在浏览器里运行的 3D 沉浸式感官互动体验，灵感致敬刘慈欣《带上她的眼睛》。  
以主角「陈舟」的身份戴上传感眼镜，替耳机另一端来自「落日六号」的「林微」走完地表的一天；并在走出草原后，通过「地球表面电台」「寄出我的视野」与「立体漫游 · 纪念册」，延续对人间晴朗与灯火的记录。

## 四大篇章联动

1. **序章 · 地球的一天** — 半径达 `220m` 的连续起伏草原与八幕叙事体验：连通 4 条山谷小径、18 块湖心踏石长堤与 5 处开放地标（东南风车崖、东谷白桦风铃林、北岭中继站 06、湖心石龛岛、西原日落石阵），配备顶部浮动罗盘、3 处 `[E]` 观景长椅、「自由漫游 + 24h 天色调节」、`Shift` 迎风滑步、`Space` 呼唤回响光柱、`[P]` 草原随手拍直存第 04 章纪念册及 `[J]` 观测手账。
2. **地球表面电台** — 可拖拽旋转与区域筛选（全球 18 城 / 南半球盛夏 / 异域极境 / 中国城市）的 3D 全息地球，覆盖南北半球冬夏风景（含悉尼、夏威夷、雷克雅未克、开普敦、京都、巴黎及国内 12 城）、场景专属音景与长按振动共鸣。
3. **视野信箱 · 漂流邮局** — 连接纪念册与远方旅人的感官漂流明信片工坊：可直接从「04 纪念册」导入已拍风景卡片，自由贴上 8 枚当地邮票、信笺边框与天气贴纸，写下短笺随环境声与录音随机漂流寄出或生成 `?signal=CODE` 分享；内置「📮 漂流收件箱」，可随机拆开来自西藏、哈尔滨、悉尼、夏威夷等地的来信与祝福并收进纪念册。
4. **立体漫游 · 纪念册** — 雕刻级 3D 微缩奇境建筑箱庭模块（上海外滩、南京晚雨图书馆、悉尼盛夏、夏威夷珊瑚湾、哈尔滨初雪、高山观星台）：支持实时软阴影、GLSL 水波纹与梯度星空、晨曦/暮色/星夜三态天光、自动缓转、城市八音盒与自然音景；内置「3 阶段奇境唤醒目标」与「寻光指引」，全唤醒可解锁外滩烟花、金光纸鹤、海豚跃湾、荧光海天灯、北国极光白鸽、高原流星雨等 6 项 3D 奇观与专属印记，支持三档取景焦距、底片滤镜与金漆封印高清 PNG 导出。

## 八幕情绪弧线（序章）

1. **I · 晨雾对焦（`06:40`）** — 拖动 3D 双重光学对焦环拨开晨雾，同步野花光影与花香。
2. **II · 湖水听风（`09:30`）** — 轻划湖面激起两道水波后校准风声共振频段；锁定瞬间触发地表金属低鸣告警。
3. **III · 孤树蒲公英（`13:15`）** — 来到悬崖孤树下长按聚风，吹散漫山蒲公英。
4. **IV · 石拱回声（`15:50`）** — 在古老石拱前发出 3 次心光共振，唤回山谷回声。
5. **V · 黄昏晚雨（`18:10`）** — 暮雨降落，点接空中飘落的 5 滴晚雨并等待云开。
6. **VI · 轻舟聚萤（`19:45`）** — 轻点暮色湖岸，为停泊木船引来 6 簇呼吸流萤。
7. **VII · 专属星河（`22:30`）** — 在夜空按顺序连起 3 颗亮星，听见耳机深处最后的坦白。
8. **VIII · 落日六号（`00:00`）** — 穿越地壳与地幔下坠至 `6,371.4 KM` 地心，与钛金球形耐压舱中的她道别与立约，将线索与记忆胶片带往后续篇章。

## 操作、无障碍与旅途印记

- **视角与漫步**：桌面端支持柔和拖拽环顾、`WASD`/方向键或点击草地信标漫步、按住 `Shift` **迎风滑步**（含下坡滑行加速）、`Space` 发出心光（并唤起未发现地标的远方垂直回响光柱）、`E` 在观景长椅坐下/起身、`P` 定格草原留影直存第 04 章纪念册，以及 `J` 打开传感观测手账；触屏端自动启用双虚拟摇杆。
- **设置与舒适度（`SettingsDrawer`）**：四通道独立音量滑杆、画质档位、减弱动效与封面快捷「闪烁抑制」开关。

## 开发与构建

```bash
npm install
npm run dev      # 启动本地开发服务
npm run lint     # 运行 oxlint 代码体检
npm run test     # 运行 Vitest 单元测试
npm run build    # TypeScript 类型检查 + Vite 生产打包
```
