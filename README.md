# 风信 · Windpost

一部在浏览器里运行的 3D 沉浸式感官互动体验，灵感致敬刘慈欣《带上她的眼睛》。  
以主角「陈舟」的身份置身清晨草原、接通随身通信终端的加密来电并戴上脑机传感眼镜，替耳机另一端来自「落日六号」的「林微」走完地表的一天；并在走出草原后，通过「地球表面电台」「视野信箱 · 漂流邮局」与「立体漫游 · 纪念册」，延续对人间晴朗与灯火的接力记录。

> **在线体验（Qoder Sites）**：`https://windpost-lzi8utsygdd.qoder.zone/`  
> **当前版本**：`v4.0.0`（2026 Qoder 高校创造力大赛 · LifeHack 赛道）

## 评委 2 分钟速览指南

1. **接通频段与戴上脑机（约 25s）**：封面点击「戴上她的眼睛」→ 首次进入可阅读「故事前情」或一键跳过 → 置身无遮挡清晨草坡接通随身终端的 **SUNSET-06 加密来电**，戴上镜框触发瞬态 **赛博神经扫描 HUD** 与 **Qwen-TTS 多角色配音**。
2. **体验草原交互与高潮地核反转（约 45s）**：轻触第 I 幕 **弹性摇曳发光野花** 后，可在顶部或左侧进度胶囊直接试跳至 **第 V 幕（手心接晚雨）** 与 **第 VII 幕（夜空连星）**，触发 `0.0 → 6,371.4 KM` 破表警报与 `11.8s` 垂直穿越地壳/地幔下坠至地心「落日六号」的静默重逢留白，随后一键直达「地球表面电台」。
3. **拨动 3D 全息地球（约 20s）**：在「地球表面电台」旋转地球、筛选南半球盛夏/极境城市，点击任意城市接收地面实况并播放 `Serena` 原声城市低语，长按触发跨地心振动共鸣。
4. **唤醒 6 城 3D 立体奇境与导出一张明信片（约 30s）**：进入「纪念册」查看六座雕刻级微缩城市箱庭（点击画面完成奇境唤醒，可看外滩烟花、图书馆金光纸鹤、高原流星雨等 3D 奇观），在「视野信箱」导入风景照片、贴上邮票并封装漂流寄出。

## 四大篇章与全栈架构

1. **序章 · 地球的一天** — 半径 `220m` 的连续起伏草原、随身加密来电入场、瞬态脑机扫描 HUD 与去 AI 味导演剪辑版八幕情感剧本：包含 4 条山谷小径、18 块湖心踏石长堤与 5 处开放地标（东南风车崖、东谷白桦风铃林、北岭中继站 06、湖心石龛岛、西原日落石阵），配备顶部浮动罗盘、3 处 `[E]` 观景长椅、「自由漫游 + 24h 天色调节」、`Shift` 迎风滑步、`Space` 声波回响光柱、`[P]` 草原留影直存第 04 章纪念册与 `[J]` 观测手账。
2. **地球表面电台** — 可拖拽旋转与区域筛选（全球 18 城 / 南半球盛夏 / 异域极境 / 中国城市）的 3D 全息地球，覆盖悉尼、夏威夷、雷克雅未克、开普敦、京都、巴黎及国内 12 城，内置 Web Audio 程序化场景音景与长按共鸣。
3. **视野信箱 · 漂流邮局** — 连接纪念册与远方旅人的漂流明信片工坊：支持直接导入已拍风景卡片、配 8 枚当地邮票、信笺边框与天气贴纸，附随实时环境音与麦克风录音生成 `?signal=CODE` 分享；内置「漂流收件箱」，可随时拆阅远方来信并收进纪念册。
4. **立体漫游 · 纪念册** — 6 座纯代码雕刻级 3D 微缩奇境箱庭（上海外滩、南京晚雨图书馆、悉尼盛夏、夏威夷珊瑚湾、哈尔滨初雪、高山观星台）：实时软阴影、GLSL 水波纹与梯度星空、三态天光、城市八音盒、3 阶段奇境唤醒奇观、三档取景焦距、16:9 宽屏无裁剪拍照、底片滤镜与金漆封印高清 PNG 导出。
5. **工程性能、AI 语音与全栈容灾**：
   - **极速首屏按需加载**：首屏核心 JS 仅约 `61 KB`（gzip `< 20 KB`），Three.js 仅在进入场景后按需懒加载。
   - **全站 48 条 Qwen-TTS 原声 + 终局留白**：基于 `qwen3-tts-flash` + 情绪指令批量合成（`Serena` 林微、`Kai` 旁白），覆盖序章全部 28 条语音与全球 20 座城市电台低语；最终章穿越地心特意保留沉默主角与纯音乐环境声，让林微的告别成为耳边最后的真人声音。
   - **Serverless + IndexedDB 双模运行与 `#/admin` 后台**：后端由 Qoder Sites Functions + PostgreSQL 提供公网视野 Feed、心跳、回声及 `owner_token` 自主撤回；网络离线时无缝降级本地存储；配备凭 `ADMIN_TOKEN` 鉴权的轻量 `#/admin` 站长审核后台（公开/私密切换、删帖、清留言）。

## 八幕情绪弧线（序章）

1. **I · 晨雾触花（`06:40`）** — 拨开晨雾，轻触随风摇曳发光的草坡野花。
2. **II · 湖畔听风（`09:30`）** — 轻划湖面激起水波并校准风频；锁频瞬间触发地表金属异响警报。
3. **III · 孤树蒲公英（`13:15`）** — 在悬崖孤树下聚起午后暖风，看白绒替她向高处飞去。
4. **IV · 石拱回声（`15:50`）** — 在山腰石拱前轻叩三次呼唤，唤回山谷回声并寄存约定。
5. **V · 手心晚雨（`18:10`）** — 应她轻声恳求「替我摸一摸雨水」，接住 5 滴晚雨并等待云开。
6. **VI · 轻舟聚萤（`19:45`）** — 轻点暮色湖岸，为停泊木船引来 6 簇呼吸流萤。
7. **VII · 真相揭开（`22:30`）** — 连起夜空 3 颗亮星，听她卸下观测站谎言，触发地核信标过载与脑机透视。
8. **VIII · 落日六号（`00:00`）** — 垂直穿越地壳与地幔下坠至 `6,371.4 KM`，在静默心跳共振与钛金球形耐压舱的琥珀微光里，替她带上人间的晴朗。

## 开发、配音合成与构建

```bash
npm install
npm run dev      # 启动本地开发服务
npm run lint     # 运行 oxlint 代码体检
npm run test     # 运行 Vitest 单元测试
npm run build    # TypeScript 类型检查 + Vite 生产打包

# （可选）使用阿里云百炼 Qwen-TTS 批量重新合成语音 MP3
$env:DASHSCOPE_API_KEY="sk-你的百炼Key"
node scripts/generate-voices.mjs
```
